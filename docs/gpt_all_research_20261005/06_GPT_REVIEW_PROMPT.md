첨부 ZIP은 한 그래프 연구의 전체 이론·실험·구현 이력입니다. 초기 Conductance/Cycle/Tree, incidence/CGAT v1/v2와 C 학습·출력 초기화, wedge 실험 전체, 로컬 E/J와 수신 복원, scalar E/J 예측·위치, 현재 copy 문맥 결합·분류·정규화 비교가 포함되어 있습니다.

먼저 `00_READ_FIRST.md`와 새 결과 `08_NORMALIZATION_FULL_RESULTS.md`를 읽고 `01_THEORY_AND_MODELS.md`부터 `05_EVIDENCE_AND_OPEN_QUESTIONS.md`까지 읽어 주세요. `REVIEW_ALL.md`는 이 자료의 합본입니다. 의문이 생기는 수식·결과는 요약에만 의존하지 말고 해당 `repository/`의 실제 코드·FULL 설정과 `evidence/` 원문으로 확인해 주세요. `07_REFERENCES_AND_SOURCE_MAP.md`와 manifest/색인으로 원본 위치를 찾을 수 있습니다.

핵심 연구 의도는 **각 로컬 그래프의 내부 이차 에너지와 로컬·홉·층 사이의 쌍선형 관계를 실제 메시지 전달·집계에 사용하는 것**입니다. 공유 C 규칙 학습, 같은 층 집계의 상쇄, 다른 집합으로 전달할 때의 누락·압축, 새로운 문맥에서의 재사용도 이 역사에 들어 있습니다.

현재 모델은 copy 공간에서 `Tρ=M(I−S)(I−ρG)(I−S)R`를 사용합니다. 현재 local/copy C는 고정 unit/local_degree이고 learned는 교차 강도 ρ의 학습입니다. 최신 정규화 비교는 전체 citation 그래프 3개·20조건에서 tuning 540회와 final 300회, 총 840회 학습과 420,000회 갱신을 완료한 서버 FULL 결과를 수령했습니다. 원시 metric/frozen/branch 행 수는 900/4,320/3,480이며 실제 데이터 사용으로 보고됐습니다. 로컬 본학습은 실행하지 않았습니다. 기존 222개 검사·DEBUG 360회/1,080회 갱신·완료 후 resume 0회 갱신은 별도 구현 검증입니다.

다음 순서로 검토해 주세요.

1. **먼저 현재 모델이 어떻게 작동하는지 쉬운 말로 설명해 주세요.** 입력이 로컬 copy로 바뀌고 내부·교차·내부 전달, merge, 예측·CE·gradient·학습으로 이어지는 흐름을 설명한 후 필요한 수식을 붙여 주세요. 기호의 차원과 뜻을 정의해 주세요.
2. **연구 의도와 실제 구현을 대응시켜 주세요.** 초기 C 학습과 scalar E/J, 현재 copy 에너지 모델을 구분하고, 무엇이 구현·실행됐는지 명확히 해 주세요. 구현이 적혀 있다는 이유만으로 사용자가 그 연구 선택을 승인했거나 목적이 달성됐다고 결론내리지 마세요.
3. **핵심 수학을 확인해 주세요.** `BᵀCB`, 실제 wedge Q와 초기 L2 제안의 차이, known-C 제한된 q의 복원, arbitrary cycle ambiguity, 중복·공통 노드 대응, `GR=MG=0`, sandwich와 persistent의 정확한 차이식, 최신 S/G의 안정성 및 D 가중 norm 조건을 점검해 주세요. 입력 의존 C의 메시지와 전체 에너지 gradient도 구분해 주세요.
4. **모든 실험의 결론을 증거 수준에 맞춰 요약해 주세요.** 실제 공식 데이터 FULL, 합성 과학 실험, fixed 감사, frozen 개입, calibration, DEBUG, 실패·부분 완료, 계획을 구분해 주세요. 동일 run의 여러 발췌를 새 반복으로 세지 마세요. 미제공 서버 CSV/checkpoint를 검증했다고 쓰지 마세요.
5. **현재 결과가 말하는 것과 아직 답하지 못한 것을 정리해 주세요.** 작용의 nonzero·학습 연결·CE 변화·accuracy 우위·복원 가능성·일반화·신규성은 다른 결론입니다. 95% 구간에 0이 들어갔다고 동등성이 증명됐다고 쓰지 마세요. 최신 FULL의 내부 정규화 효과, 교차 정규화 효과, 같은 C·intra에서 cross를 추가한 효과를 나누고 accuracy와 CE를 각각 평가해 주세요. 기존 여섯 조건의 재학습은 근사 재현이며 bitwise 동일성 검증으로 쓰지 마세요.
6. **오류나 중요한 설계 간극이 있으면 구체적으로 지적해 주세요.** 해당 파일·함수·수식·원문 수치를 제시하고, 확인된 문제와 가능한 원인/가설을 구분해 주세요. 성능 저하를 residual·초기화·정규화 중 하나로 증거 없이 확정하지 마세요.
7. 마지막에 **현재 진행 단계에서 우선 판단할 질문을 최대3개**만 제시해 주세요. 새 모델을 임의로 설계하거나 추가 실험을 길게 나열하기 전에 현재 자료의 해석을 마무리해 주세요. 모델·데이터·epoch·seed 규모를 임의로 줄이지 마세요.

선행연구와 정확히 같은지, 새로운지 단정하려면 논문 원문·저자 코드와 수식 단위로 비교해야 합니다. 이 ZIP은 연구 이력 정리이며 완전한 문헌 조사 결과가 아닙니다. 추가 문헌을 확인했다면 출처와 추론을 구분해 주세요.
