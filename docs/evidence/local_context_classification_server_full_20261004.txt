## 실제 비교

각 층은 투영 특징을 모든 로컬 copy에 복제하고 intra→cross→intra→균등 merge한다.
두 C조건은 고정 unit/local_degree이며, 학습하는 것은 learned 조건의 seed당 cross 강도 θ 하나다.
ρ=sigmoid(θ)를 두 macro 층에서 공유한다. Fixed는ρ=1, off는ρ=0이며 θ 파라미터가 없다.
