# 지금까지의 전체 실험 — GPT 전달 안내

기준일: 2026-10-04. 현재 저장소와 사용자가 전달한 서버 출력에 근거한 검토 묶음이다.
지금 필요한 검토는 **원래 연구 질문과 실제 구현·실험이 어디까지 일치하는가**다.

## 현재 연구 질문

각 노드의 1홉 로컬 그래프에서 발생행렬로 내부 이차 에너지를 계산하고,
서로 다른 로컬 그래프·홉 집합 사이의 쌍선형 관계를 함께 구성하려 한다.
핵심은 이 항들을 일관되게 결합해 더 넓은 그래프의 에너지와 새로운 전파·집계를 만들 수 있는가다.
이전에는 특징으로 연결 가중치 C를 생성하는 규칙이 여러 부분구조에서 학습·일반화되는지도 연구했다.
이 두 목적을 모든 실험이 이미 충족했다고 가정하면 안 된다.

## 가장 먼저 알아야 할 구현 상태

현재 로컬 예측 모델은 **고정 C에서 E/J를 각각 계산해 노드 특징에 추가하는 후보 모델**이다.
E는 국소 라플라시안의 에너지이고, J는 국소 라플라시안을 적용한 결과들의 겹친 노드 내적이다.
이들을 합쳐진 물리 그래프 라플라시안으로 조립하고 그 연산자로 전파하는 모델은 아직 구현하지 않았다.
GCN과 동일한 조건의 직접 비교도 최근 E/J 실험에는 없다.

최근 위치별 결과에는 PubMed local_degree·출력층 J의 +0.24pp 후보가 있다.
그러나 정확도 개선 구간은 54개 기본 대비 비교 중 하나이고, CiteSeer 출력층 J는 성능을 낮췄다.
이 결과를 원래 통합 에너지 아이디어 전체의 성공 또는 실패로 확대하지 말아야 한다.
