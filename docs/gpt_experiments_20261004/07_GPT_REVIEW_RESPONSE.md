## 2. 두 검토에서 확인한 수학적 내용

- 현재 E는 국소 Dirichlet energy, J는 공통 원래 노드에서 국소 집계 결과끼리의 내적이다.
- 현재 분류 forward는 `base + e*w_E + j*w_J`다. 통합 연산자를 적용하는 전파가 아니다.
- 국소 집계 결과의 합을 제곱하는 에너지를 택하면 내부항은 L² 유형이다.
  이를 모든 가능한 통합 에너지의 유일한 선택으로 설명하지 않는다.
- 로컬 에너지들의 합 자체는 물리 엣지의 occurrence 가중치가 합쳐진 양의 가중 라플라시안 에너지다.
  원래 물리 가중치를 한 번씩 센 에너지와 같게 만들려면 중복을 조정해야 한다.
- 겹치는 로컬을 서로소 partition처럼 바로 붙일 수 없다.
  원래 노드 좌표에 embedding하거나, 로컬 사본 사이의 동일 노드 제약을 명시해야 한다.
- 물리 그래프의 cross edge는 교차 블록과 양쪽 대각 degree에 함께 들어간다.

현재 raw 조합을 전역 좌표에서 쓰면

\[
E_v+E_u+2J_{vu}
=\operatorname{tr}\bigl(Z^\top
(\mathcal L_v+\mathcal L_u+\mathcal L_v\mathcal L_u+\mathcal L_u\mathcal L_v)Z\bigr).
\]

첫 검토의 0–1–2 경로, 중심 0과 1, unit C 예시 행렬

\[
\begin{pmatrix}6&-7&1\\-7&9&-2\\1&-2&1\end{pmatrix}
\]

은 직접 전개와 일치한다. +1 비대각은 양의 물리 엣지 가중치의 일반 라플라시안과 다르다.
이 예의 고유값은 0, 1, 15여서 **이 예 자체는 PSD**다.
비대각 부호가 다른 것과 PSD가 아닌 것은 서로 다른 판정이다.
이 수치 예시는 대수 확인이며 서버 FULL 결과가 아니다.
이번 반영 작업에서도 NumPy로 이 행렬 전개와 고유값을 직접 확인했다.

전체 \(\|\sum_v\mathcal L_vZ\|^2\)를 목표로 한다면
원래 중심이 인접하지 않아도 공통 노드에서 생기는 교차항을 포함해야 한다.
현재 adjacent-center pair 목록은 모든 overlap pair 목록과 다르다.
기존 목록을 학습 편의를 위해 줄였다는 뜻이 아니라 서로 다른 목표 연산자라는 뜻이다.

두 번째 검토가 제안한 \(B_v^\top K_{vu}B_u\)도 가능한 쌍선형 표현이다.
그 모양 자체가 PSD나 물리 그래프 라플라시안을 보장하지 않는다.
내부 블록·교차 블록·계수·경계 degree·동일 노드 제약을 함께 검사해야 한다.

## 3. 성능 원인은 아직 확정하지 않았다

두 번째 검토의 “원래 아이디어의 제대로 된 구현이 아니기 때문에 GCN보다 낮다”는 문장은
현재 증거보다 강한 인과 주장이다.
정확한 결론은 **현재 결과가 원래 통합 에너지 모델의 성능을 평가하지 않았다**는 것이다.

최근 로컬 모델에는 동일 조건의 직접 GCN 대조가 없다.
이전 wedge 분류의 GCN 점수를 현재 로컬 모델의 공정한 비교 점수로 재사용하지 않는다.
통합 에너지로 바꾸면 성능이 높아진다는 결과도 아직 없다.
스칼라 압축, 기본 P_C² 집계, 주입 크기 등은 대조가 필요한 후보 원인이다.

## 4. 다음 검증 질문

**현재의 1차 내부 에너지 E를 유지하면서, 경계와 중복을 처리한 전체 에너지가 어떤 연산자인가?**

에너지 값·연산자 작용·미분을 비교하는 감사가 이 질문에 대응한다.

2. 같은 물리 엣지에 서로 다른 local_degree C가 있을 때 어떤 하나의 가중치 규칙을 쓸 것인가?
3. E/J를 통합 에너지에서 만든 전파로 사용할 것인가, 다른 목적의 특징으로 사용할 것인가?
