ZIP SHA256: `1b2ea7981d8273e06cabafbce4f848b54b27ba722327008e12279041756f9087`。

현재 구현·네 가지 수정·실험 계약·검증 기록은 `research/edge_metric_relations/`에 둔다. 기존 결과를 보존한다. 서버 FULL을 아직 실행하지 않은 현재 구현과 DEBUG를 제안 ZIP의 작은 대수 검사나 과거 연구 결과와 섞지 않는다.
