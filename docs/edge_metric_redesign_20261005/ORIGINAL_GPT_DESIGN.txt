**이번에는 연구 질문을 세 개로 분리해서 설계하겠습니다.**

**① 반복 집계에서 어떤 관계가 실제로 구별되지 않는가 → ② 엣지 사이 결합을 바꾸면 그 관계를 다르게 처리하는가 → ③ 그 차이가 학습·일반화·분류에 도움이 되는가.**

이 세 질문을 같은 결과로 뭉뚱그리지 않겠습니다. 아래는 **새 설계안**이며, 기존 copy 모델의 완료된 구현이나 실험으로 설명하지 않습니다.

먼저 직전 답변의 오류부터 고정하겠습니다.

## 1. 수학적 기준부터 정확히 고정합니다

\[
B\in\mathbb R^{m\times n}
\]

를 물리 엣지×노드 발생행렬이라고 하겠습니다.

| 기호 | 정의 | 의미 |
|---|---|---|
| \(L_0\) | \(B^\top B\) | 무가중 라플라시안 |
| \(L_d\) | \(B^\top C_dB,\ C_d=\operatorname{diag}(c_e)>0\) | 일반적인 가중 라플라시안 |
| \(Q_C\) | \(B^\top C_{\rm edge}B\) | 비대각 엣지 결합까지 허용한 연산자 |

정확한 관계는

\[
\boxed{L_0^2=B^\top(BB^\top)B}
\]

이고, 가중 라플라시안을 두 번 적용하면

\[
\boxed{
L_d^2
=
B^\top\underbrace{C_dBB^\top C_d}_{\text{두 번의 집계가 만드는 엣지 결합}}B
}
\]

입니다.

**임의의 \(B^\top CB\)가 \(L_0^2\)라는 뜻은 아닙니다.** 앞서 \(L=B^\top CB\)라는 올바른 정의 자체를 잘못됐다고 설명한 것은 제 오류였습니다. 첨부의 기존 C는 기본적으로 **양의 대각 엣지 가중치**이며, 비대각 \(C_{\rm edge}\) 학습은 이번에 별도로 제안하는 확장입니다. 01_THEORY_AND_MODELS

또

\[
L_0^k=B^\top(BB^\top)^{k-1}B
\]

는 **동일한 고정 선형 라플라시안을 반복한 경우**입니다. 비선형 활성화와 층별 가중치가 들어간 모든 GNN을 이 식으로 동일시하지 않습니다.

### 이번 실험의 핵심 가설

> **대각 엣지 가중치 또는 고정 라플라시안의 반복이 사용하는 관계 결합과 비교하여, 로컬 내부 이차항과 로컬 사이 쌍선형항을 직접 구성한 연산이 필요한 관계를 더 잘 구별하고 활용하는가?**

여기에 **“어떤 조건에서 정보가 실제로 소실되는가”라는 원래 질문을 독립된 검사로 포함**합니다. 성능이 좋아졌다는 이유로 정보 보존을 주장하거나, 행렬이 달라졌다는 이유로 표현력이 증가했다고 주장하지 않습니다.

## 2. 첫 실험은 새 분류 모델이 아니라, 손실 가설을 직접 검사하는 것입니다

현재까지는 known-C·전체 관측에서 실제

\[
q=C_dBX
\]

를 복원할 수 있다는 결과가 나왔습니다. 따라서 같은 조건을 놓고 다시 “라플라시안 집계가 정보를 영구적으로 없앤다”는 결론을 기대하면 안 됩니다. 01_THEORY_AND_MODELS

### 2.1 무엇을 보고 무엇을 복원하는지 먼저 정합니다

고정된 전파 연산을 \(F\), 관측할 노드들을 선택하는 행렬을 \(O\)라 하면

\[
\boxed{Y=OFX}
\]

로 씁니다.

동일한 전체 그래프를 계산한 뒤, **읽는 범위만** 다음처럼 나눕니다.

| 관측 | 질문 |
|---|---|
| 전체 노드 출력 | 전체 관측으로 원래 관계를 결정할 수 있는가? |
| target node 출력 | 그 노드 표현 하나에 어떤 관계가 남는가? |
| target의 1홉 출력 집합 | 다음 국소 계산이 이용할 수 있는 범위에서는 무엇을 결정할 수 있는가? |

이것은 학습 그래프를 잘라서 규모를 줄이는 것이 아닙니다. **전체 계산을 유지하면서 정보가 제공되는 범위를 통제하는 실험**입니다.

복원·구별 대상은 기존 감사에서 정의한 **실제 엣지 메시지 \(q_v\), 로컬 에너지 \(E_v\), 개별 로컬 관계 \(J_{vu}\)**를 사용합니다. 처음부터 두 스칼라 평균으로 다시 압축하지 않습니다.

### 2.2 “관계가 사라졌다”는 것을 이렇게 확인합니다

서로 다른 입력 \(X_1,X_2\)에 대해

\[
OFX_1=OFX_2
\]

인데도

\[
E_v(X_1)\ne E_v(X_2)
\]

또는

\[
J_{vu}(X_1)\ne J_{vu}(X_2)
\]

이면, **그 관측으로는 해당 관계를 결정할 수 없습니다.**

이것이 행렬 잔차나 에너지 감소보다 직접적인 증거입니다.

작은 그래프에서는 이 조건을 영공간으로 정확히 검사할 수 있습니다. 예를 들어 스칼라 입력에서

\[
\psi(x)=x^\top K_\psi x,\qquad K_\psi=K_\psi^\top
\]

를 복원하려면, 모든 입력에 대한 결정 가능성의 조건은

\[
\boxed{
\ker(OF)\subseteq\ker(K_\psi)
}
\]

입니다. 이 조건을 위반하는 방향을 찾으면, 관측은 같지만 목표 관계가 다른 입력 쌍을 직접 만들 수 있습니다.

**다만 이렇게 만든 입력 쌍은 의도적인 구별 불가능성 검사입니다. 자연 데이터에서 그런 경우가 얼마나 흔한지는 별도로 측정해야 합니다.**

그리고 반드시 **역방향 검사**도 합니다. 새 연산자가 놓치지만 baseline이 구별하는 관계도 있다면, “정보가 더 많이 보존됐다”가 아니라 **구별하는 방향이 달라졌다**고 설명해야 합니다.

### 2.3 현재 copy 모델에는 이미 확인할 수 있는 중요한 한계가 있습니다

현재 고정 선형 모델에서

\[
A=I-S,\qquad
M=D_{\rm copy}^{-1}R^\top
\]

로 쓰면

\[
T_0=MA^2R,\qquad
T_\rho=MA(I-\rho G)AR
\]

입니다. 현재 구현이 사용하는 형태입니다. 00_READ_FIRST

여기서 직접 유도하면

\[
T_0z=0
\Rightarrow
z^\top D_{\rm copy}T_0z
=\|ARz\|^2=0
\Rightarrow
T_\rho z=0.
\]

즉,

\[
\boxed{\ker(T_0)\subseteq\ker(T_\rho)}
\]

입니다.

**동일한 고정 S/G와 전체 노드 출력을 비교하는 한, 현재 cross는 J-off가 정확히 구별하지 못하는 입력 차이를 되살릴 수 없습니다.**

이것은 현재 copy 모델의 분류가 무의미하다는 뜻이 아닙니다. **그 모델의 효과를 ‘전역적으로 소실된 정보의 복구’로 설명하면 안 된다는 뜻**입니다. 부분 관측에서의 접근성, 관계의 가중 방식, 분류 결과는 다른 질문입니다.

### 이 감사의 범위

기존 **198개 합성 그래프 + citation 3개 = 201개 전체**를 유지합니다. 합성 특징 3,168개와 실제 citation 특징도 그대로 사용합니다. 기존 고정 감사의 규모입니다. 04_LOCAL_AND_COPY_EXPERIMENTS

반복 횟수는 \(1,2,4,8,16\)으로 두되, 다음을 분리합니다.

\[
L^kX,\qquad (I-\eta L)^kX,\qquad \text{실제 모델의 반복 출력}.
\]

**순수 \(L\) 반복, smoothing 반복, 비선형 GNN을 같은 것으로 측정하지 않습니다.** 작은 합성 그래프는 직접 분해하고, 큰 citation은 희소 연산과 반복 복원으로 검사하며, 근사 계산을 정확한 rank나 영공간 증명으로 보고하지 않습니다.

## 3. 새 모델 후보는 하나입니다: 내부 metric과 교차 metric을 같은 에너지에 넣습니다

이번 후보는 **현재 node-copy consensus를 조금 수정하는 모델이 아닙니다.**

\[
\boxed{
\text{로컬별 엣지 차이}
\rightarrow
\text{대각 내부 metric + 비대각 로컬 간 metric}
\rightarrow
\text{같은 에너지의 노드 메시지}
}
\]

라는 별도 구성입니다.

### 3.1 공통 노드와 중복 엣지는 먼저 맞춥니다

각 로컬은 기존과 같이

\[
S_v=\{v\}\cup N(v)
\]

의 유도 부분그래프를 사용합니다.

\(P_v\)를 노드 선택 행렬, \(r_e\)를 물리 엣지 \(e\)가 포함된 로컬의 수라고 하면

\[
\mathscr B_v
=
\operatorname{diag}(r_e^{-1/2})B_vP_v
\]

를 만들고,

\[
\mathscr B=
\begin{bmatrix}
\mathscr B_1\\
\vdots\\
\mathscr B_N
\end{bmatrix}
\]

로 쌓습니다.

**이것은 같은 물리 특징에서 로컬 엣지 차이를 계산하기 위한 표현입니다. 동일 노드의 상태를 독립적으로 계속 진화시키는 기존 copy 모델과 다릅니다.**

중복 보정을 명시적으로 넣는 이유는 cross를 껐을 때 어떤 기준 연산이 되는지 알기 위해서입니다.

로컬 가중치를 \(c_{v,e}\)라 하면 cross-off는

\[
\boxed{
Q_{\rm diag}
=
B^\top\operatorname{diag}(\bar c_e)B,\qquad
\bar c_e=\frac1{r_e}\sum_{v:e\in E_v}c_{v,e}
}
\]

가 됩니다.

`unit`이면 정확히 \(L_0\)입니다. `local_degree`이면 물리 엣지별 평균 C의 가중 라플라시안입니다.

**이 보정은 raw 로컬 에너지의 단순 합과 다릅니다.** 둘을 같은 값이라고 하지 않고 raw/corrected 에너지를 모두 기록합니다. 기존 감사에서도 중복 보정 전후의 차이는 이미 관측됐습니다. 붙여넣은 텍스트(1)

### 3.2 내부항과 교차항을 실제 블록으로 정의합니다

전체 로컬 엣지 공간의 대각 가중치를 \(\mathscr D_\theta\), 로컬 사이 엣지 결합을 \(K_\theta\)라고 두겠습니다.

\[
\boxed{
\mathscr C_\theta
=
\mathscr D_\theta^{1/2}
(I+\rho K_\theta)
\mathscr D_\theta^{1/2}
}
\]

\[
\boxed{
Q_\theta
=
\mathscr B^\top\mathscr C_\theta\mathscr B
}
\]

입니다.

\(K_\theta\)는 대칭이고, 같은 로컬 내부 블록은 0으로 둡니다. 그러면

\[
\mathcal E_\theta(X)
=
\frac12\operatorname{tr}(X^\top Q_\theta X)
\]

를 전개했을 때

\[
\boxed{
\mathcal E_\theta
=
\frac12\sum_v
\operatorname{tr}
\left(
g_v^\top\mathscr D_vg_v
\right)
+
\rho\sum_{v<u}
\operatorname{tr}
\left(
g_v^\top
\mathscr D_v^{1/2}
K_{vu}
\mathscr D_u^{1/2}
g_u
\right),
\quad g_v=\mathscr B_vX.
}
\]

**앞 항이 로컬 내부 이차 에너지이고, 뒤 항이 로컬 사이 쌍선형 교차항입니다. 둘은 같은 \(\mathscr C_\theta\)에서 나옵니다.**

이제는

\[
\langle L_vX_v,L_uX_u\rangle
\]

를 별도로 계산해서 붙이거나,

\[
e_vw_E+j_vw_J
\]

라는 스칼라 특징 분기로 바꾸지 않습니다. **전체 에너지의 연산자 \(Q_\theta\)를 실제 메시지에 사용합니다.**

### 3.3 PSD를 보장하되, wedge 형태로 강제하지 않습니다

첫 후보에서는

\[
K_\theta=K_\theta^\top,\qquad
\|K_\theta\|_2\le1,\qquad
\rho=0.5
\]

로 사전 고정하는 것을 제안합니다.

그러면

\[
\mathscr C_\theta\succ0
\]

이고,

\[
\boxed{
(1-\rho)Q_{\rm diag}
\preceq Q_\theta
\preceq(1+\rho)Q_{\rm diag}
}
\]

가 됩니다.

이것은 **제안한 안정화 제약**이지 최적값을 발견했다는 뜻은 아닙니다. 또한 이 제한된 family가 모든 비대각 C나 모든 \(L^k\)를 표현한다고 주장하지 않습니다.

중요한 차이는 교차항을 미리

\[
-\|g_v-g_u\|^2
\]

같은 한 관계로 고정하지 않는다는 것입니다. 허용 범위 안에서 **교차 계수의 부호와 배치**를 학습합니다.

### 3.4 어떤 엣지끼리 결합할지도 고정합니다

첫 실행은 기존 자료와 같은 **인접 중심의 로컬 쌍 전체**를 사용합니다. 그 안에서 **서로 다른 물리 엣지이며 실제 공통 끝점을 갖는 모든 엣지 쌍**을 결합 후보로 둡니다.

같은 물리 엣지가 두 로컬에 반복된 경우는 cross로 세지 않습니다. 그것은 새로운 엣지 관계가 아니라 대각 가중치의 재계산과 섞이기 때문입니다.

이 제한은 **첫 후보의 명시적인 지지집합**입니다. 모든 홉·모든 로컬 관계를 이미 표현한다고 하지 않습니다. 대신 그 범위 안에서 top-k나 임의 sampling으로 관계를 버리지 않습니다.

가중치는 공유 MLP가 두 엣지의 변화 관계와 로컬 구조 통계에서 생성합니다. 계산용 엣지 방향을 뒤집어도 결과가 바뀌지 않도록 공통 끝점을 기준으로 차이를 정렬하고,

\[
K' = Q_{\rm sign}KQ_{\rm sign}
\]

를 만족시키도록 구성합니다. 입력·대칭화·정규화의 구체식은 첨부 설계서에 고정했습니다.

**MLP의 출력은 관계 계수입니다. 노드로 전달되는 전체 특징 벡터를 E/J 두 스칼라로 압축하는 구조가 아닙니다.**

## 4. 실제 전파와 대조군을 함께 고정합니다

### 4.1 에너지 계산과 메시지 적용을 일치시킵니다

각 층에서

\[
Z=\operatorname{Dropout}(H)F_\ell
\]

를 만든 후

\[
\boxed{
U=Z-\tau N_0Q_\theta(Z)N_0Z
}
\]

로 전파합니다.

\(N_0\)는 기준 대각 연산자의 노드 degree로 만든 **topology-only 정규화**입니다. on/off마다 다른 graph maximum으로 나눠서 cross 효과와 크기 효과를 섞지 않습니다.

설계서에서는 대각 가중치의 학습 배율을 \((1/2,2)\), \(\rho=0.5\)로 제한하고, 공통 \(\tau=1/3\)을 사용하는 첫 계약을 제시했습니다. 그러면 **가중치를 고정한 전파 행렬의 spectral norm이 1 이하**가 되도록 상계를 줄 수 있습니다.

이 보장은 전체 비선형 분류기의 안정성 보장이 아닙니다. 또한 입력 의존 \(Q_\theta(Z)\)를 사용하므로 위 메시지는 **전체 adaptive 에너지를 Z에 대해 미분한 값과 일반적으로 다릅니다.** CE 역전파는 C/K 생성기의 입력 의존성까지 그대로 미분합니다. 이 구분은 기존 자료의 원칙도 유지합니다. 01_THEORY_AND_MODELS

### 4.2 가장 중요한 대조는 “비대각 결합”과 “같은 정보를 읽는 대각 가중치”입니다

각 C recipe(`unit`, `local_degree`)에서 아래 6조건을 비교합니다.

| 조건 | 대각 C | 비대각 결합 | 확인할 질문 |
|---|---|---|---|
| **D0** | 고정 | 없음 | 기준 연산 |
| **D1** | 학습 | 없음 | 일반 가중 라플라시안 학습 효과 |
| **F0** | 고정 | 고정 구조 계수 | 교차 구조 자체의 효과 |
| **F1** | 고정 | 학습 | 교차 계수 학습의 효과 |
| **F2** | 학습 | 학습 | 두 종류의 가중치를 함께 사용한 효과 |
| **DA** | 같은 pair 정보를 읽고 학습 | 없음 | 추가 pair 정보·파라미터 때문인지 검사 |

**DA가 특히 중요합니다.**

F2만 두 엣지의 관계를 읽고, D1은 각 엣지의 양 끝만 읽게 하면, F2가 좋아져도 **입력을 더 줘서 좋아진 것인지 비대각 결합이 좋아서인지** 구분할 수 없습니다.

DA는 F2와 같은 pair MLP와 입력을 가지되, 그 결과를 **대각 가중치만 만드는 데 사용**합니다. 따라서

\[
\boxed{\text{F2 대 DA}}
\]

가 이번 설계의 핵심 비교입니다.

완전히 같은 함수 공간인 대조는 아니므로 실제 연산량·특징 의존 범위도 함께 기록합니다.

### 4.3 GCN과 다항식 대조도 같은 실행에서 새로 학습합니다

위 12조건에 다음 3개를 추가합니다.

| 기준선 | 역할 |
|---|---|
| 표준 2-layer GCN | 외부 성능 기준 |
| 같은 2개 projection에서 각 집계를 \(P_{\rm GCN}^2\)로 수행 | 단순 2홉 전파 대조 |
| 2차 라플라시안 다항식 | \(L,L^2\)의 학습 가능한 조합 대조 |

표준 GCN은

\[
P_{\rm GCN}
=
\widetilde D^{-1/2}(A_{\rm adj}+I)\widetilde D^{-1/2}
\]

를 사용합니다. 새 에너지 모델을 GCN이라고 부르거나 \(B^\top B\)를 그대로 곱하는 모델로 대신하지 않습니다. [arXiv](https://arxiv.org/pdf/1609.02907)

2차 다항식 대조는

\[
p(\widetilde L)=a_0I+a_1\widetilde L+a_2\widetilde L^2
\]

를 사용합니다. 다항식 계수를 학습하는 대조가 필요한 이유는, **고정된 \(L^2\) 하나를 이겼다는 것만으로 학습 가능한 다항식 family보다 낫다고 할 수 없기 때문**입니다. 다항식의 국소화와 희소 계산은 기존 spectral filtering 연구에서도 다뤄집니다. 여기서 제안한 대조를 해당 논문의 전체 재현이라고 부르지는 않습니다. [arXiv](https://arxiv.org/pdf/1606.09375)

**총 15조건입니다. 기존 20조건 정규화 실험을 줄이거나 재명명하는 것이 아니라, 다른 질문을 위한 새 비교표입니다.**

## 7. 구현에서 다시 같은 실수를 막는 장치

이번 설계에서 반드시 차단할 것은 다음입니다.

**첫째, 새 교차항을 다시 scalar E/J lift나 기존 copy consensus G로 바꾸지 않습니다.** 그러면 다른 실험이 됩니다.

**둘째, C가 달라졌다는 것과 실제 노드 연산이 달라졌다는 것을 따로 기록합니다.**

\[
\|\Delta C\|,
\qquad
\|B^\top\Delta CB\|,
\qquad
\|B^\top\Delta CBX\|
\]

를 나누어 봅니다. C의 변화가 최종 연산에서는 보이지 않을 수 있습니다.

**셋째, cross-off에서도 projection·정규화·대각 가중치·학습 예산을 유지합니다.** Frozen 제거와 처음부터 off로 학습한 비교도 별도로 저장합니다.

**넷째, 모든 선언된 관계를 정확히 처리합니다.** 큰 관계 목록은 chunking과 재계산으로 처리하되, GPU 메모리가 부족하다는 이유로 관계나 그래프를 몰래 버리지 않습니다. 복잡도는 물리 엣지 수뿐 아니라 **로컬 엣지 occurrence 수와 cross pair 수**에 의존한다고 보고합니다.

**다섯째, 통합 에너지와 실제 메시지 미분을 모두 검사합니다.** 에너지 값만 우연히 같거나, forward는 맞지만 가중치 생성기 미분이 끊겨 있는 경우를 통과시키지 않습니다.

**기존에는 “다른 연산을 만들어 분류해 보자”가 먼저였고, 정작 무엇이 소실되며 무엇을 보완하는지는 뒤로 밀렸습니다. 이번에는 순서를 바꿉니다.**

\rightarrow
