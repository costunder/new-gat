# E/J 위치별 재학습 서버 결과 — 2026-10-04

**E/J를 넣는 층을 바꿔도 정확도가 일관되게 좋아지지는 않았다.**
Cora에서는 첫 층 E가 CE를 낮췄고, PubMed의 `local_degree`·출력층 J가
같은 C의 base보다 정확도와 CE를 함께 개선한 한 후보로 남았다.
CiteSeer에서는 출력층 J가 두 C 모두 정확도를 낮췄다.

## 제출한 결과와 확인 범위

사용자가 제출한 전체 요약을 [서버 원문](evidence/local_placement_server_full_20261004.txt)에
84,818 bytes 그대로 보존했다. SHA-256은
`a5b7e6db68d60f7cd5e13b3864d7d33d2c4ff021d1d4e6ec1fc2c1e5875cf408`다.

원문은 tuning 540회·final 300회·계약 420,000 optimizer update와 coverage 검증을 보고한다.
전송된 표의 행 수는 아래와 같이 계획한 집계 범위와 일치한다.

| 원문 표 | 확인한 행 수 |
| --- | ---: |
| 데이터·조건의 train/validation/test 요약 | 60 |
| E/J를 함께 쓴 성능 상호작용 | 18 |
| 같은 seed의 재학습 비교 | 174 |
| 두 층의 분기 관측 | 120 |
| 모든 활성 층 범위의 frozen 제거 | 150 |

서버의 `completion.json`, 실제 결과 경로, code digest, seed별 CSV와 checkpoint는
이번 첨부에 없다. 따라서 표의 수와 수치를 확인했으며,
840회 학습의 원시 파일·hash·update 기록을 독립적으로 다시 검증한 상태는 아니다.
원문은 resource 후보 1,729개와 후보의 epoch 시간 0.0064513–2.6678초를 보고한다.
이 범위는 전체 소요 시간이나 최종 선택한 epoch 시간의 추정치가 아니다.
선택한 GPU·VRAM·packing·chunk와 전체 elapsed 값은 첨부되지 않았다.

## 무엇을 다시 학습했는가

각 고정 C(`unit`, `local_degree`)에서 base 한 개와
E만·J만·E+J × 첫 층(`hidden`)·출력층(`output`)·두 층(`all`)을 비교했다.
세 데이터셋·20조건, 2층·hidden 64·run당 500 epoch를 유지하는 실험이다.
LR/checkpoint는 validation으로 선택하며 모든 final checkpoint를 확정한 뒤 test를 평가한다.

E는 1홉 induced local의 내부 이차 에너지, J는 인접한 서로 다른 local의
공통 원래 노드 대응에서 계산한 쌍선형 관계다. 현재 층의 특징으로 계산한
스칼라 E/J에 활성 층의 학습 벡터를 곱해 기본 노드 전파에 더한다.
발생행렬·기본 전파·C·정규화는 [모델 수식](../research/local_energy_relations/placement/MODEL_MATH.md)과 같다.
이번 C는 학습하지 않는다.
첫 층은 lift당 64개, 출력층은 클래스 수 K개의 파라미터를 쓰고 현재 Z도 다르므로,
위치 비교에는 특징 공간과 추가 파라미터 수의 변화가 함께 들어간다.

## E+J를 넣는 위치별 test 정확도

단위는 %이며 final 5seed의 평균이다. base는 위치에 공통이다.

| 데이터 | C | base | 첫 층 E+J | 출력층 E+J | 두 층 E+J |
| --- | --- | ---: | ---: | ---: | ---: |
| Cora | unit | 76.22 | 76.34 | 75.96 | 76.04 |
| Cora | local_degree | 74.34 | 74.42 | 74.38 | 74.56 |
| CiteSeer | unit | 67.24 | 67.14 | 64.94 | 65.06 |
| CiteSeer | local_degree | 64.90 | 64.84 | 63.70 | 63.62 |
| PubMed | unit | 79.60 | 79.54 | 79.32 | 79.44 |
| PubMed | local_degree | 78.94 | 78.90 | 78.96 | 79.04 |

**E+J를 첫 층에 넣는 방법이 모든 데이터에서 우세했다고 볼 수 없다.**
첫 층 E+J 여섯 조건의 같은 C base 대비 accuracy 95% 구간은 모두 0을 포함한다.
CiteSeer `unit`의 출력층·두 층 E+J는 각각 −2.30pp [−3.8804, −0.71962],
−2.18pp [−3.6736, −0.68638]로 정확도 악화 구간이다.

## 같은 C의 base와 비교한 주요 결과

아래 Δ는 재학습한 조건−base다. Accuracy는 양수, CE는 음수가 개선이다.
구간은 같은 public split·같은 5seed의 paired t 95% 구간이며 다중 비교 보정은 없다.

| 데이터·조건 | Δaccuracy pp [95%] | ΔCE [95%] |
| --- | --- | --- |
| Cora unit·첫 층 E | +0.0800 [−0.35369, +0.51370] | −0.0027974 [−0.0040867, −0.0015082] |
| Cora local_degree·첫 층 E | +0.0600 [−0.14777, +0.26777] | −0.0023179 [−0.0034673, −0.0011684] |
| CiteSeer unit·출력층 J | −2.78 [−3.5914, −1.9686] | +0.017584 [+0.0011707, +0.033997] |
| CiteSeer local_degree·출력층 J | −2.08 [−3.9761, −0.18387] | +0.021422 [+0.012266, +0.030577] |
| PubMed local_degree·출력층 J | +0.24 [+0.051693, +0.42831] | −0.0026657 [−0.0046963, −0.00063507] |

같은 C의 base와 비교한 54개 조건 중 정확도 구간이 완전히 양수인 것은
PubMed `local_degree__between__output` 한 개다. 완전히 음수인 비교는 7개다.
CE는 11개에서 개선 구간, 4개에서 악화 구간이다.
Cora 첫 층 E+J도 두 C 모두 CE를 낮췄지만 정확도 구간은 0을 포함한다.
PubMed 후보의 정확도 79.18%는 `unit__base` 79.60%보다 낮다.
이 후보를 전체 조건에서 선택한 최종 모델로 부르지 않는다.

## 실제 학습·사용과 제거 반응

60개 조건 모두 선택한 LR은 0.01이고 train accuracy는 100%다.
등록된 96개 활성 E/J lift의 checkpoint 평균 norm은 모두 양수이며,
비활성 분기는 0으로 기록되어 있다. 분기가 학습·forward에서 쓰인 관측이다.

원문의 분기/base norm 비율은 첫 층 E 약 0.9–3.3%, J 약 0.33–1.68%,
출력층 E 약 5.2–12.0%, J 약 3.2–16%다. 이는 모든 노드·채널의 norm 비율이며
정확도에 기여한 비율이나 전체 정보의 보존율은 아니다.

PubMed `local_degree__between__output`의 J를 같은 checkpoint에서 제거하면
test CE가 −0.0058299 [−0.0073259, −0.0043338], accuracy가 +0.24pp 바뀐다.
그러나 별도 재학습한 J 모델은 base보다 CE·정확도가 좋았다.
두 비교는 양립한다. J를 쓰며 학습한 projection을 고정한 제거와
J 없는 모델의 전체 재학습은 다른 연산이며, 제거 반응은 공동 학습된 경로의 의존성을 보여 준다.

기존 base/all 24개 조건의 accuracy 평균·표본 std는 앞선 제출 요약과 같다.
CE 일부 마지막 표시 자리는 다르며 원시 checkpoint·CSV가 없어 원인을 확정하지 않는다.

## 현재 판단과 다음 후보

이 결과는 **주입 위치만 바꾸면 보편적으로 좋아진다**는 주장을 뒷받침하지 않는다.
현재 스칼라 E/J lift가 충분한 표현인지도 이 실험 하나로 판정할 수 없다.
독립 split/graph 일반화·learned C 성공·사이클 정보 복원을 입증한 결과가 아니다.
54개 무보정 비교 중 한 정확도 후보는 후속 확인이 필요하다.

다음 설계 후보는 첫 층 64채널에서 E/J를 채널별로 유지하는 대조다.
현재 `e = mean_f(e_f)`, `j = mean_f(j_f)`로 요약한 뒤 64차원 벡터를 곱한다.
후보는 같은 B·C·정규화·hidden 64를 쓰며 `e_f w_E,f`, `j_f w_J,f`를 더한다.
분기별 학습 파라미터 64개를 그대로 맞춰 채널 요약 방식의 차이를 비교할 수 있다.
스칼라 요약이 성능 부진의 원인이라는 결론은 아직 없으며, 이 대조는 설계 제안이다.

후속 논의에서는 E/J를 같은 통합 에너지의 내부항·교차항으로 구성한다는 연구 의도를 다시 확인했다.
현재 J와 E가 그 결합을 직접 구현하지 않으므로, 채널별 대조에 앞서 에너지 정의와 실제 전파 연결을 정리해야 한다.
이 차이는 [전체 실험 전달용 수식 정리](gpt_experiments_20261004/01_RESEARCH_AND_MATH.md)에 기록했다.
