# GPT 검토 요청

이 패키지는 **CGAT 연구 v2.0: C 학습만 분리한 초기 실험**이다.
기존 여러 보완을 포함한 information_flow_v2 후보와 구분해서 검토해 달라.

먼저 사용자가 이해할 수 있는 말로 현재 코드가 무엇을 계산하는지 설명하고,
이번 질문인 다음 세 항목에 코드가 실제로 대응하는지 확인해 달라.

1. 같은 층 입력을 고정한 갱신 전후 비교로 C 생성 규칙이 배우는지 확인하는가?
2. 실제 C·수신 노드별 반영 비중·CE gradient·optimizer 갱신을 구분해서 기록하는가?
3. learned와 별도 학습한 fixed 조건, learned checkpoint의 C=1 개입을 구분하는가?

추가 확인:

- 8층·256차원·8헤드와 200epoch 전체 train pass를 유지하는가?
- 한 forward에서 같은 노드·엣지를 사용하고, 두 조건의 초기값·샘플 순서를 확인하는가?
- q²·경계 에너지·교차항·층간 흐름 저장·복원·cycle 기능이 실제 실행 경로에 없는가?
- 현재 생성기의 문맥·8회 내부 반복을 바꾸지 않았는가?
- 관측 기능이 본래 출력·gradient·optimizer 갱신에 영향을 주지 않는가?

`VERIFICATION.md`와 `evidence/`의 결과는 합성 단위·smoke 검사다.
실제 데이터에서 C의 유용성이나 속도를 확인한 결과로 해석하지 말아 달라.
지원 코드에 여러 과거 모델이 들어 있어도 v2.0 forward에 모두 포함되는 것은 아니다.
실행 경로의 시작점은 `experiments/c_learning_only/train.py`와 `model.py`다.

답변은 다음 순서로 간단히 작성해 달라.

1. 현재 구현을 평이하게 설명.
2. 의도와 일치하는 점, 확인된 오류를 근거 파일·함수와 함께 설명.
3. 구현된 사실 / 테스트로 확인한 사실 / 아직 본학습이 필요한 주장을 구분.

미래 실험 제안을 현재 구현 사실처럼 쓰지 말아 달라. v2.1의 기능은 아직 정하지 않았다.
