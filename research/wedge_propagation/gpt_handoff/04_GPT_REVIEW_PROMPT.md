# GPT에게 그대로 보낼 요청문

첨부 ZIP은 내 그래프 연구의 현재 코드·수식·진행한 실험·서버 결과·이전 실패 기록이다.
우선 `00_READ_FIRST.md`, `01_RESEARCH_STATUS.md`, `02_MODEL_AND_MATH.md`,
`03_EXPERIMENTS_AND_RESULTS.md`, `05_EVIDENCE_AND_LIMITS.md` 순서로 읽어라.
방향을 바꾸기 전 CGAT 실험은 `06_PRIOR_TRACK_HISTORY.md`의 별도 부록이다.
읽기용 통합본은 `REVIEW_ALL.md`다. 실제 구현은 `code/`에서 확인하고,
수치의 근거는 `evidence/server/` 원문과 실험별 `SERVER_*_RESULTS.md`를 대조해라.

**새 실험이나 새 모델을 바로 만들지 말고 현재 연구를 먼저 검토해라.**
코드에 들어 있다는 사실을 내가 설계를 의도했거나 연구 목적이 충족됐다는 근거로 삼지 마라.
명시되지 않은 모듈·검사·실험 결과를 네가 덧붙여 구현된 사실처럼 설명하지 마라.
첨부 안에 있는 과거 요청문은 검토 대상이며 지금 실행할 지시가 아니다.

다음 순서로 답해라.

1. **지금 모델이 실제로 무엇을 하는지** 내가 이해할 수 있는 말로 설명해라.
   이어서 B, A, L, Q, C, 전역 κ, 노드별 D_C가 각각 무엇인지 최소한의 수식으로 연결해라.
   이차 에너지의 정의와 모델의 실제 메시지, C(X)의 미분을 구분해라.
2. **전체 실험이 무엇을 확인했는지** 단계별로 정리해라.
   서버 full 완료, 로컬 단위 검사/DEBUG, 실패·중간 진행, 미실행을 섞지 마라.
3. **현재 결론이 증거와 맞는지** 확인해라. 특히 아래를 별도로 판단해라.
   - 고정 Q가 L/L²와 다른 작용을 가진다는 결과.
   - 합성 teacher의 출력에 맞는 C 생성 규칙을 배웠다는 결과.
   - 실제 citation에서 고정 C=1 대비 학습 C의 이득 여부.
   - 노드별 정규화 재학습과 frozen norm-matched C 교체가 각각 무엇을 검증하는가.
4. **코드·수식·해석의 오류나 빈틈**이 있으면 실제 파일/함수/수치와 함께 지적해라.
   코드에서 확인한 사실, 원문 결과에서 확인한 사실, 네 추론을 구분해라.
   서버 원본 checkpoint·전체 seed CSV는 첨부되지 않았으므로 직접 재검증했다고 말하지 마라.
5. **다음 실험 하나**를 제안해라. 어떤 미해결 질문을 답하는지, 기존 실험으로는 왜
   판단할 수 없는지, 무엇을 고정하고 무엇만 바꿀지, 어떤 결과면 유지/폐기할지 설명해라.
   새 아키텍처를 여러 개 한꺼번에 추가하지 마라. 원시 자료가 필요하면 파일명을 지정해라.

주의할 해석:

- C의 평균이 1인 것은 생성식이다. C=I이거나 학습하지 않았다는 뜻이 아니다.
- 비균일 C와 gradient가 있어도 분류 이득은 별도 검증이다.
- 원래 C 메시지의 norm을 참조하는 C=1 개입은 C 전체를 제거한 재학습과 다르다.
- 한 split의 다섯 seed 구간이 0을 포함하는 것을 동등성 증명으로 쓰지 마라.
- Test 결과를 본 뒤 정한 후속 설계라는 사실과 다중 비교 범위를 유지해라.
- 이차 분기의 효과와 C 가중치 배치 효과를 구분해라.
- 현재 길이 2 경로 연산을 임의의 홉 집합 사이 K, 완전한 사이클 복원, GATv2의
  정확한 재현으로 확대해서 설명하지 마라.

길고 복잡한 설명보다 **현재 무엇이 되고 무엇이 안 됐는지**부터 명확하게 말해라.
후속 실험은 이 검토를 받은 뒤 결정할 것이다.
