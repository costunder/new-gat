# GPT 검토 이후: 연구 목적과 현재 구현의 범위

2026-10-03. 사용자 첨부 `d45c6de6-b684-43fb-ac8e-263d7d1bc542`와
그 뒤의 정정 `66944be6-db4b-4e4f-9d21-c2c09f4f3cd6`을 현재 코드와 대조한 기록이다.
기존 실험·설정·코드·결과는 보존한다. 이 문서는 새 모델의 구현 완료나 새 실험 결과가 아니다.

## 1. 이번 검토에서 가장 중요한 정정

원래 질문은 **각 로컬 그래프의 내부 특징 차이와, 서로 다른 로컬·홉·층 사이의 관계가
집계와 전달을 거치면서 어떻게 남거나 구별되지 않게 되는가**다.

현재 wedge 분기는 연속된 두 엣지의 차이 `g₁,g₂`에 대해

\[
c_p\|g_2-g_1\|^2
=c_p\|g_1\|^2+c_p\|g_2\|^2-2c_p\langle g_1,g_2\rangle
\]

를 선택했다. 쌍선형 교차항은 있지만 내부 항과 교차항의 계수가
`a=d=c_p, b=−c_p`로 묶여 있다. 이 **wedge 분기**는 일반적인 로컬 사이 관계의 특수형이다.
전체 분류기에는 별도의 고정 일차 L 분기도 있으나, 로컬별 내부 E와 로컬 사이 J를
개별 상태로 기록하고 층 사이에서 추적하는 기능은 없다.

예를 들어 3노드 경로의 특징이 `(0,1,2)`이면 엣지 차이는 `(1,1)`이다.
단위 가중치의 내부 엣지 에너지는 `1²+1²=2`이고 wedge 에너지는 `(1−1)²=0`이다.
두 연산이 측정하는 대상이 다르다.

**따라서 현재 wedge 분류 결과와 C 교체 결과는 해당 후보 모델의 결과로 남긴다.
이 결과로 원래 로컬 에너지·쌍선형 관계 연구 전체의 성공이나 실패를 판정하지 않는다.**
첫 첨부의 aligned/shuffled C 재학습 제안은 wedge 후보의 후속 대조다.
이번 원래 연구 목적의 정정을 대신하는 다음 단계로 자동 채택하지 않는다.

## 2. 원래 구상을 표현하는 기본식

로컬 v의 원래 노드 집합을 S_v라 하고, 해당 로컬의 발생행렬을 B_v라 한다.
H의 노드 행을 선택하는 P_v를 두면

\[
G_v^{(\ell)}=B_vP_vH^{(\ell)}\in\mathbb R^{m_v\times F}
\]

는 해당 층의 로컬 엣지 차이다. 양의 대각 엣지 가중치 C_v를 쓰는 내부 에너지는

\[
E_v^{(\ell)}=\operatorname{tr}[(G_v^{(\ell)})^\top C_v^{(\ell)}G_v^{(\ell)}].
\]

다른 로컬 u와의 대응 W_{v,u}는 m_v×m_u 크기다. 공통 특징 좌표에서 교차 관계는

\[
J_{v,u}^{(\ell,r)}
=\operatorname{tr}[(G_v^{(\ell)})^\top W_{v,u}^{(\ell,r)}G_u^{(r)}].
\]

E_v와 E_u라는 scalar를 곱한 것이 아니다. 양쪽의 **엣지 차이 특징**을 비교하는 교차항이다.
고정 가중치와 같은 비교 좌표에서는 E_v+E_u+2J가 블록 이차형식으로 전개된다.
서로 다른 층을 비교한다고 더 높은 차수의 차분을 계산해야 하는 것은 아니다.

가중치를 고정하면 한쪽에 전달하는 교차 메시지의 자연스러운 형태는
`B_vᵀ W_{v,u} G_u`다. 실제 신경망에서 이를 어떤 노드에 모으고 다른 분기와 결합할지는
아직 별도의 설계다. 이 수식만으로 구현된 메시지 패싱·학습 모델이라고 주장하지 않는다.

## 3. 구현 전에 명시할 항목

다음은 수식에 기호만 추가해서 해결되는 항목이 아니다. 실제 코드와 실험 계약에 명시해야 한다.

1. **로컬의 정의:** S_v와 로컬 엣지의 범위. 중심-이웃 엣지만 쓰는 star와
   1홉 노드 집합 안의 모든 원래 엣지를 쓰는 induced graph를 구분한다.
   이웃 u의 1홉 로컬과 v의 정확히 2홉 shell도 서로 다르다.
2. **대응 W:** 어느 로컬 쌍과 어느 엣지 쌍이 연결되는지, 대응을 구조로 정하는지
   특징에서 생성하는지. 임의 dense W 또는 공통 엣지에만 한정한 W를 자동 선택하지 않는다.
3. **겹침·방향:** 원래 노드/엣지 ID, 로컬별 엣지 순서와 방향, 중복 집계 규칙.
   엣지 방향을 뒤집으면 G의 부호와 W의 대응 부호를 함께 처리해야 한다.
4. **층의 비교 좌표:** 채널 수가 다르면 공통 공간으로 맞춰야 한다.
   같은 채널 수라고 서로 다른 층의 학습 좌표가 자동 정렬되는 것은 아니다.
5. **관측과 사용:** E/J를 로그에만 기록하는지, 다음 상태·메시지·예측에 사용하고
   task loss로 학습하는지. 에너지 관측을 이유로 에너지 최소화 loss를 자동 추가하지 않는다.
6. **계산 규모:** 전체 로컬과 대응의 수, 중복 엣지 수, 메모리·처리량을 계측하고
   batch·sparse 연산·cache·streaming을 설계한다. 편의를 위한 경로/노드 cap을 추가하지 않는다.

이 항목을 고정하지 않은 상태에서 기존 C gate에 분기를 더하는 것은 원래 연구의 구현이라고
볼 수 없다. 기존 분류기의 두 층·hidden 64·500 epoch 계약을 이 새 모델의 승인된 예산으로
자동 계승하거나 임의로 축소하는 것도 피한다.

## 4. 먼저 검증해야 하는 관계

- 같은 로컬의 내부 E와 다른 로컬 사이 J를 각각 계산한다.
- 같은 층의 집계 전후와 서로 다른 단계의 전달 전후를 나눠 관측한다.
- 노드 집합이 달라질 때 유지·제외된 노드/엣지와 경계 대응을 함께 기록한다.
- 비교 시 가중치를 고정한 변화와, 특징 변화에 따라 C/W를 다시 생성한 변화를 구분한다.
- 메시지 norm, 내부 에너지, 교차항, 복원 가능성은 각자 측정한다.

고정 대칭 T에 대해 에너지는 `XᵀTX`, 메시지는 `TX`, 메시지 norm 제곱은 `XᵀT²X`다.
따라서 norm match를 에너지 보존 검사로 해석하지 않는다.
E/J를 관측한다고 소거된 사이클 성분이나 누락된 메시지를 자동 복원하는 것도 아니다.

전체 블록을 비음수 에너지로 쓰려면 PSD 조건을 확인한다. 여러 로컬을 함께 더할 때는
각 쌍의 PSD만으로 전체 블록의 PSD를 보장하지 못하므로 전체 결합을 검사해야 한다.
부호 있는 J를 관계 특징으로
쓰는 것 자체에 PSD 제약이 필수인 것은 아니다. C/W가 특징에서 생성되면 고정 가중치에
대한 이차·쌍선형과 가중치 생성까지 포함한 비선형 함수를 구분한다.
Task loss의 역전파와 adaptive energy의 전체 gradient도 별개다.

## 5. 첫 검토에서 좁혀야 하는 네 주장

### C의 전역 평균과 분류 메시지

최종 C가 `raw/mean(raw)`이므로 C 자체는 전역 통계에 의존한다는 지적은 맞다.
하지만 현재 native 분류 메시지에서는 공통 양의 배율 a가 상쇄된다.

\[
D_{aC}=aD_C,\quad S_{aC}=a^{-1/2}S_C,\quad
S_{aC}A^\top(aC)AS_{aC}=S_CA^\top CAS_C.
\]

Global 분기도 κ(aC)=aκ(C)이므로 같은 불변성이 있다.
그러므로 **C 평균 정규화 자체를 native 분류 메시지의 비국소 의존 원인으로 확대하면 부정확하다.**
Global κ의 최대값, RMS의 전체 엣지 통계 등 다른 문맥 의존은 남는다.
κ나 D_C로 재정규화하지 않는 synthetic 메시지는 이 분류의 불변성과 구분한다.
Hold-κ처럼 C만 바꾸고 정규화의 일부를 고정하는 개입에도 이 불변성을 자동 적용하지 않는다.

### Train accuracy 100%

Train top-1의 포화는 CE 수렴·gate 최적화·LR의 적합성까지 증명하지 않는다.
현재 결과가 유용한 일반화를 입증하지 못했다는 판단은 유지하되,
훈련·최적화 문제를 이 수치 하나로 모두 배제하지 않는다.

### Fresh aligned/shuffled 비교

설계 요인으로 permutation만 바꿀 수 있지만, 조건별 재학습 후 C의 값·분포·D_C·projection·
α/β가 동일해지는 것은 아니다. 이 비교는 각 구조에서 학습한 모델의 결과를 비교한다.
단일 frozen 배치 효과만 바꾼 인과 검사와 구분한다.

### 새 stratified split

같은 노드를 다시 나누면 이전 test와 겹칠 수 있다. 새 split은 반복 평가의 범위를 넓히지만
기존 test를 보며 개발한 이력을 자동으로 지우지 않는다. 독립적인 확인 실험이라는 표현은
실제 데이터/평가의 분리와 사전 고정 범위에 맞춰 사용해야 한다.

원래 연구 목표와 wedge 특수형의 간극, 첫 검토의 해석 보충을 문서로 기록했다.
새 모델·학습 실행기·실험 결과를 만들거나 기존 scientific source/config를 변경하지 않았다.
