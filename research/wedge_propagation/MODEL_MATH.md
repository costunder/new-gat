# 구현 수식과 결과의 의미

## 입력에서 출력까지

1. 단순 무방향 그래프의 물리 엣지를 한 번씩 기록한다. B의 한 행은 `−e_u+e_v`다.
2. 중심 j의 서로 다른 두 이웃 {i,k}를 한 번씩 열거한다. A의 한 행은 `e_i−2e_j+e_k`다.
3. 같은 X에 LX, L²X, QX를 계산한다. 각 그래프의 16개 scalar 입력은 특징 축에서 동시에 계산한다.
4. 출력·에너지·스펙트럼·다항식 잔차를 저장한다. 학습 파라미터와 loss는 없는 고정 연산 검사다.

\[
(AX)_p=(x_k-x_j)-(x_j-x_i).
\]

QX는 경로의 이차 차분을 `(1,−2,1)` 계수로 세 노드에 다시 모은 결과다.
모든 경로에 가중치 1을 사용한다. 에너지는

\[
E_Q(X)=X^\top QX=\sum_p(x_i-2x_j+x_k)^2.
\]

다차원 X를 사용하면 열별 에너지를 기록하고, 전체 에너지는 그 합이다.
에너지의 입력 gradient는 `2QX`다. 단위 검사에서 직접 확인한다.
Raw QX의 적용과 `X−τQX` 형태의 에너지 감소 업데이트는 서로 다른 연산이며 현재 측정은 전자다.

## 엣지 표현과 정확한 빠른 구현

각 경로에서 중심에 닿는 두 엣지 e,f에 대해

\[
R_{p,e}=-B_{e,j},\qquad R_{p,f}=-B_{f,j}
\]

로 두면 A=RB다. 엣지 방향을 바꾸면 R의 부호도 바꾼다. 이 R을 일반 line graph 발생행렬로 간주하지 않는다.

\[
Q=L^2+B^\top\operatorname{diag}(d_u+d_v-4)B.
\]

`operators.fixed_wedge_fast_apply`는 이 항등식으로 모든 경로의 결과를 정확하게 계산한다.
특징 수 F에 대해 연산 비용은 O(EF)다. 고정 가중치 1일 때의 식이다.
경로별로 달라지는 learned C2에는 그대로 사용할 수 없다.
보정 계수는 음수일 수 있으므로 clipping하지 않는다. Q 전체가 A.T A이므로 PSD다.
거리 2의 양의 비대각 항이 생길 수 있어 Q를 양의 엣지 가중치만 가진 일반 라플라시안으로 해석하지 않는다.

## L²로 환원되는 범위

모든 엣지에서 degree sum이 s로 일정하면

\[
Q=L^2+(s-4)L.
\]

Cycle에서는 Q=L²다. Star에서도 s가 일정하므로 L과 L²의 조합으로 정확하게 표현된다.
Degree가 일정한 d-regular 그래프에서는 Q=L²+2(d−2)L다.
비정규 그래프라는 사실만으로 다항식 연산과 차이가 생긴다고 가정하지 않는다.

각 그래프에서 측정하는 잔차는

\[
r_G=\frac{\min_{u,v}\|Q-uL-vL^2\|_F}{\|Q\|_F}.
\]

Float64에서 두 basis의 Frobenius norm을 맞춘 뒤 2×2 Gram 행렬의 pseudoinverse로 구한다.
계수는 원래 scale로 돌려 저장한다. Rank deficiency도 pseudoinverse로 처리한다.
이 계수는 해당 평가 그래프의 전체 행렬을 사용한 설명용 최적 적합이며 학습 모델의 성능이 아니다.
Q=0이면 상대 잔차는 undefined, absolute 잔차는 0이다.
Q의 전체 scale을 바꿔도 이 상대 잔차는 동일하다.

## 강도를 맞춘 보조 비교

PSD 연산자의 전체 고유값을 직접 계산하고 최대값 ρ(T)=||T||₂로 나눈다.
L, L², Q 각각의 normalized 출력 norm과 에너지를 함께 저장한다.

\[
\Delta_X=
\frac{\|(Q/\rho(Q))X-(L^2/\rho(L^2))X\|_2}
     {\|(Q/\rho(Q))X\|_2}.
\]

각 scalar 입력마다 계산한다. 연산자 norm이 0이거나 분모가 1e−12 이하이면 상대값을 undefined로 기록한다.
Nullspace 차원은 `|λ|≤1e−10 max(1,ρ(T))`인 고유값 개수로 기록한다.
`num_components`는 L의 같은 기준으로 구한다. 모든 고유값도 저장하므로 허용오차의 영향을 확인할 수 있다.

## 이후 연구와의 연결

이번 코드는 경로 연산의 독립 작용을 확인하는 출발 단계다.
후속 실험에서만 두 엣지 차분의 관계를 입력받는 공유 생성기로 C2를 만들고,
`A.T C2(X) A X`를 출력 loss에 연결해 새 그래프에서 같은 규칙이 통하는지 검증한다.
그 단계의 teacher·데이터 split·모델 폭·optimizer·epoch는 별도 계약으로 확정한다.
현재 출력에 checkpoint나 분류 정확도는 포함되지 않는다.
