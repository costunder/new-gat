# 로컬 그래프 에너지와 그래프 사이 관계: 수식

이 단계는 **고정된 연산을 검사하는 실험**이다. C와 집합 사이 W를 학습하지 않는다.
분류기·encoder·CE loss도 없다. 먼저 에너지, 관계, 중복 집계를 같은 실제 연결 위에서 확인한다.

## 1. 한 노드 주변의 로컬 그래프

원래 무방향 그래프를 G=(V,E)라 하자. 물리 엣지는 한 번만 저장하고,
원래 노드 ID가 작은 끝에서 큰 끝으로 같은 방향을 정한다.
중심 v의 노드 집합은 `S_v={v}∪N(v)`다.
`E_v`는 S_v 안에 양 끝이 있는 **모든 원래 엣지**다.
중심에서 이웃으로 연결되는 엣지뿐 아니라 이웃끼리의 엣지도 포함한다.
새 연결을 만들거나 집합 밖의 엣지를 관측한 것처럼 쓰지 않는다.

B_v는 E_v×S_v 발생행렬이다. 각 행에는 tail −1, head +1이 있다.
H_v는 공통 노드 특징 H에서 S_v에 해당하는 행을 선택한 것이다.
C_v는 양의 엣지별 대각행렬이며 이번에는 두 고정 규칙만 비교한다.

- `unit`: 모든 엣지의 c=1.
- `local_degree`: 엣지 (a,b)의 c=2/(deg_v(a)+deg_v(b)). degree는 이 로컬 induced graph에서 계산한다.

엣지가 없으면 해당 메시지와 에너지는 0이다. 존재하는 엣지 양 끝의 degree는 양수다.
학습한 attention 점수나 원래 그래프의 global degree 보정으로 설명하면 안 된다.

## 2. 같은 로컬 그래프의 내부 이차 에너지

먼저 엣지 차이와 메시지를 계산한다.

\[
G_v=B_vH_v,\qquad q_v=C_vG_v,\qquad d_v=B_v^\top q_v.
\]

가중 라플라시안과 내부 에너지는 다음과 같다.

\[
L_{v,C}=B_v^\top C_vB_v,\qquad
E_v=\operatorname{tr}(H_v^\top L_{v,C}H_v)
   =\sum_{e\in E_v}c_{v,e}\|G_{v,e}\|_2^2\ge0.
\]

한 특징이면 HᵀLH는 숫자다. 여러 특징이면 trace는 채널별 에너지의 합이다.
합성 데이터의 독립 scalar columns와 citation의 하나의 벡터 특징을 metadata로 구분한다.

**에너지와 메시지 제곱 크기는 다르다.** 메시지 크기는

\[
F_v=\|q_v\|_F^2=\sum_ec_{v,e}^2\|G_{v,e}\|_2^2.
\]

C=I일 때는 E_v=F_v다. 일반적인 C에서는 c와 c²의 차이가 있으므로 같은 양으로 쓰지 않는다.
d_v는 노드로 합친 부호 있는 메시지이며, 에너지는 합치기 전 변화의 크기를 요약한다.
에너지 한 숫자가 개별 메시지의 부호와 내용을 모두 보존하는 것은 아니다.

## 3. 서로 다른 로컬 집합 사이의 쌍선형 관계

서로 연결된 중심 v와 u의 집합은 겹칠 수 있지만 크기와 엣지가 다를 수 있다.
각 B를 원래 전체 노드의 열 좌표로 확장한 행렬을 \(\bar B_v,\bar B_u\)라 하자.
로컬 노드 메시지도 같은 원래 노드 좌표에 0으로 확장한다.
새 학습 행렬을 만들지 않고 실제 공통 연결과 노드만 대응시킨다.

### 같은 물리 엣지에서의 관계

\[
J_{\rm shared}(v,u)
 =\sum_{e\in E_v\cap E_u}\langle q_{v,e},q_{u,e}\rangle.
\]

엣지 방향을 원래 ID로 통일했으므로 같은 엣지가 반대 부호로 잘못 대응하지 않는다.
같은 방향을 쓰더라도 시점이 다르면 내적은 음수일 수 있다.

### 같은 노드에서 만나는 모든 메시지의 관계

\[
K_{vu}=\bar B_v\bar B_u^\top,\qquad
J_{\rm node}(v,u)
=\operatorname{tr}(q_v^\top K_{vu}q_u)
=\sum_{i\in S_v\cap S_u}\langle d_{v,i},d_{u,i}\rangle.
\]

K는 E_v×E_u 직사각형 행렬이다. 실제 서로 다른 집합의 발생행렬을 양쪽에 둔 관계다.
G_v와 G_u로 표현하면 가운데 가중치는 \(W_{vu}=C_vK_{vu}C_u\)다.
이는 이번 고정 규칙과 실제 incidence 대응으로 결정된 W다. 임의의 모든 W를 학습한 결과는 아니다.

같은 물리 엣지의 발생행렬 행끼리 내적은 2이므로

\[
J_{\rm distinct}=J_{\rm node}-2J_{\rm shared}
\]

는 한 공통 노드에서 만나는 **서로 다른 엣지끼리**의 기여다.
공통 노드를 통과하는 엣지 방향에 따라 부호가 달라진다.
이 쌍선형 관계들을 항상 양의 에너지라고 부르거나 PSD라고 강제하지 않는다.

이번 실험은 원래 물리 엣지의 양방향 중심 쌍 (v,u), (u,v)를 모두 계산한다.
같은 단계의 관계, v의 t단계와 u의 t+1단계 관계를 구분한다.
그 둘의 비교는 공통 좌표를 가진 고정 reference states에서 수행한다.

## 4. 비교하는 H0, H1, H2는 학습 층이 아니다

원래 전체 그래프의 unit 라플라시안 L=BᵀB로 두 번 확산시킨다.

\[
H^{(0)}=X,\quad H^{(t+1)}=H^{(t)}-\tau LH^{(t)},\quad
\tau=\frac1{2d_{\max}},\quad t=0,1.
\]

모든 로컬 그래프는 같은 전체 상태에서 해당 행을 선택한다.
두 로컬 집합의 특징 차이는 다른 노드 선택과 reference 시간 차이에서 온다.
encoder로 채널 좌표를 바꾸지 않으므로 내적의 채널 대응은 공통이다.
학습된 두 GNN 층의 좌표가 자연히 정렬됐다는 근거로 쓰면 안 된다.
엣지 없는 그래프에서는 L=0이고 모든 상태가 같다.

같은 로컬 그래프의 시간 관계 \(\langle q_v^{(t)},q_v^{(t+1)}\rangle_F\)도 별도로 기록한다.
그래프 사이 관계와 같은 집합의 시간 관계를 섞지 않는다.

## 5. 사이클 성분과 알려진 C 아래의 복원

unit 로컬 라플라시안 \(L_v=B_v^\top B_v\)로 실제 q를 분리하면

\[
q_{\rm cycle}=q_v-B_vL_v^\dagger d_v,
\qquad B_v^\top q_{\rm cycle}=0.
\]

이 성분은 **Euclidean 기준에서 노드 합에 보이지 않는 실제 메시지 성분**이다.
사이클이 존재하는지, 실제 q에 이 성분이 있는지, 그 q가 복구 불가능한지는 다른 질문이다.

이번 q는 임의의 엣지 값이 아니라 알려진 양의 C 아래의 \(q_v=C_vB_vH_v\)다.
모든 로컬 노드의 d를 관측하면

\[
\hat q_v=C_vB_vL_{v,C}^\dagger d_v=q_v
\]

가 성립한다. H의 연결 성분별 상수는 q에 영향을 주지 않는다.
따라서 q_cycle이 0이 아니어도 이 제한된 q를 복원할 수 있다.
실제 수치 계산의 방정식 잔차와 복원오차를 모두 기록한다.
일부 노드만 남긴 뒤의 정확한 역복원이나 비선형·압축 뒤의 복원을 주장하지 않는다.

## 6. 한 집합에서 이웃 집합으로 넘기는 감사

S_v에서 만든 d_v를 S_u로 옮길 때 **공통 노드의 d만 복사**한다.
S_u의 새 노드에 원래 d가 있던 것처럼 채워 넣지 않는다.
전달 전 전체, 공통 노드에 남는 부분, S_v에서 빠지는 부분의 norm을 기록한다.
제곱 norm에는 \(\|d_v\|^2=\|d_{\rm retained}\|^2+\|d_{\rm dropped}\|^2\)가 성립한다.

또한 두 ego의 공통 엣지, 각 ego에만 있는 엣지와 공통/비공통 노드를 잇는 경계 엣지의
메시지·에너지 기여를 구분한다. 이는 관측·전달 범위의 감사다.
누락 성분을 모델이 예측해 복원했다는 실험도, 부분 관측 역문제를 푼 실험도 아니다.
이 복사 연산은 bookkeeping·진단이며 H_next를 만들 때 사용하지 않는다.
H1/H2의 업데이트는 4절의 전체 물리 라플라시안 확산만 사용한다.

## 7. 모든 ego를 모을 때 생기는 중복

한 물리 엣지는 여러 ego에 포함된다. 그 횟수를 m_e라 하면

\[
\sum_v E_v=\sum_{e\in E}\bigl(\sum_{v:e\in E_v}c_{v,e}\bigr)\|BH_e\|^2.
\]

raw 합은 같은 연결을 반복해서 센 값이다. 원래 물리 그래프의 unit 에너지는
\(E_{\rm physical}=\sum_{e\in E}\|BH_e\|^2\)다.
각 occurrence를 m_e로 나누면

\[
E_{\rm corrected}=\sum_v\sum_{e\in E_v}\frac{c_{v,e}}{m_e}\|BH_e\|^2
=\sum_{e\in E}\bar c_e\|BH_e\|^2,
\quad \bar c_e=\frac1{m_e}\sum_{v:e\in E_v}c_{v,e}.
\]

unit 조건에서는 corrected가 원래 unit 에너지와 같다.
local_degree 조건에서는 물리 엣지의 평균 C를 사용한 에너지와 같으며, unit 에너지와 같다고 하지 않는다.
전체 원래 노드·엣지와 모든 ego를 사용했는지 확인한 뒤 이 항등식을 검사한다.
