# 수신 측 집계 실험

**서로 다른 로컬에서 받은 메시지를 합칠 때 직접 숨는 차이와, 현재 메시지 제약 아래 실제로 복원 가능한 정보를 구분하는 고정 진단**이다.

이전 `local_energy_relations` 실험의 전체 201개 입력을 그대로 사용한다. 모든 induced 1홉 로컬과 양방향 인접 로컬 전달을 계산한다. `unit`/`local_degree` C와 H0/H1/H2를 유지한다. 모델·분류기 학습은 없다.

## 비교하는 표현

| 조건 | 관측 |
|---|---|
| `tagged` | 송신 로컬별 receipt |
| `sum` | 수신 로컬·원래 노드별 합 |
| `sum_within` | 합과 실제 내부 이차 에너지 |
| `sum_between` | 합과 실제 로컬 사이 쌍선형 관계 |
| `sum_both` | 합·내부 에너지·쌍선형 관계 |

모든 로컬이 하나의 전역 H를 제한하고 C가 알려진 양의 가중치인 이번 조건에서는, 합의 수신 중심 행이 원래 그래프의 directed Laplacian을 포함한다. 따라서 합 전체가 H를 연결성분별 상수까지 결정하며 실제 q/E/J도 결정한다.

**receipt에서 합으로 갈 때 숨는 송신별 성분이 있어도, 이번 실제 메시지가 영구히 복구 불가능하다고 뜻하지 않는다.** 실험은 이 차이를 실제 복원오차로 검사한다. E/J를 추가한 forward 관측도 기록하되, 동일한 합에서 복원한 H로 그 추가 값들을 재현할 수 있는지 확인한다. E/J를 decoder에 넣어 개선한 복원이나 분류 성능을 주장하지 않는다.
