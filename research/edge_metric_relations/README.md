# 엣지 관계를 직접 학습하는 새 실험

현재 질문은 **국소 그래프 안의 이차 에너지와 국소 그래프 사이의 쌍선형 관계를 하나의 연산자로 연결했을 때, 반복 집계가 구별하지 못하는 관계를 더 잘 다루는가**다.

이번 트랙은 `EDGE_METRIC_REDESIGN.zip`의 A/B/C 제안을 구현한다. 기존 wedge·scalar E/J·node copy 문맥 결합 실험과 결과는 그대로 둔다. 이 트랙에는 아직 서버 FULL 결과가 없다.

## 모델이 하는 일

1. 원래 그래프의 모든 1홉 induced local을 만든다. 같은 물리 엣지가 여러 local에 들어가면 발생행렬 행을 `1/sqrt(등장 횟수)`로 보정한다.
2. 인접한 두 중심의 local에 있는 **서로 다른 물리 엣지** 중 실제 끝점을 공유하는 모든 쌍을 연결한다.
3. 공유 MLP가 노드 특징과 관계의 구조에서 양의 대각 가중치와 엣지 쌍 결합 계수를 만든다.
4. 대각항과 쌍선형항을 함께 가진 엣지 계량을 발생행렬 사이에 넣는다. 그 연산자의 메시지를 다음 표현에 직접 사용한다.
5. 분류 CE 또는 합성 메시지 복원 손실에서 생성기까지 미분하고 학습한다.

핵심은 에너지 숫자를 분류기에 덧붙이는 것이 아니다. **엣지 사이 결합이 실제 전파 연산을 바꾼다.** 다만 그 결합이 분류나 새로운 구조에서 유용한지는 B/C 결과로 판단해야 한다.

## 세 단계

| 단계 | 질문 | FULL 규모 | 학습 |
|---|---|---|---|
| A | 관측과 반복 집계 뒤 개별 국소 메시지·에너지·관계가 얼마나 구별/복원되는가? | 기존 전체 201그래프, 원래 모든 특징 | optimizer 0 |
| B | 새 결합 규칙이 알려진 메시지 목표를 학습하고 다른 크기·family로 옮겨가는가? | 531그래프, 각 16개의 독립 scalar 실현 | 240 seed 학습 × 500 epoch = 120000 update |
| C | 비대각 결합이 대각 모델·pair-informed 대각 모델·다항식 기준선보다 분류에 도움이 되는가? | citation 3개, 전체 노드/엣지/특징, 15조건 | tuning 405 + final 225 = 630회, 315000 update |

B의 고정 조건과 선형 fit 기준선은 optimizer 학습 횟수에 포함하지 않는다. 자원 calibration의 임시 update도 따로 센다. C의 test는 모든 final checkpoint와 LR 선택을 잠근 뒤 평가한다. FULL C는 같은 코드의 완료된 A/B 결과를 요구하며, A/B의 좋은 점수를 진행 조건으로 강제하지 않는다.
